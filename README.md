# Ясно — первый проект портфолио

Демонстрационный сайт вымышленного клинингового сервиса. Создан 28 сентября 2026 года.

## Что работает

- Адаптивный лендинг: услуги, процесс, FAQ и описание учебного проекта.
- Калькулятор: три вида уборки, площадь 20–250 м², три дополнительные услуги, минимальная база 4 500 ₽.
- Демонстрационный путь заявки: расчёт → просмотр → создание в текущей вкладке → скачивание текстового расчёта.
- Клавиатурная навигация, диалог с Escape, сокращённое движение по настройке браузера.
- Два структурированных WebMCP-инструмента при поддержке браузером: настройка и чтение расчёта.

## Ограничения

Это не действующая компания. Цены примерные, клиенты, отзывы и финансовые показатели не выдумываются. Настоящие контактные данные не собираются. Тестовая заявка хранится только в sessionStorage текущей вкладки; при запрете хранилища остаётся в памяти до перезагрузки. Telegram, CRM, серверная база и реальные уведомления не подключены. Закрытие вкладки завершает локальное хранение. На другой компьютер заявки не переносятся.

## Запуск

Из папки проекта: `node serve.mjs`. Открыть http://127.0.0.1:4173. Сайт не требует установки зависимостей. Для размещения используются файлы из `dist`.

Изменение тарифов: объект `services`, объект `extras` и минимум в `dist/app.js`; соответствующие видимые подписи также находятся в `dist/index.html`.

## Авторство и материалы

Дизайн и реализация подготовлены с ИИ для личного портфолио пользователя. Изображение интерьера создано ImageGen; это иллюстрация концепции, не фотография выполненного заказа. Шрифт Manrope загружается через Google Fonts, предусмотрен системный запасной шрифт. Никакие чужие работы не выдаются за выполненные коммерческие проекты.

## Карточка для портфолио

**Ясно / Лендинг клинингового сервиса.** Учебный проект. Задача — показать услуги и дать посетителю предварительный расчёт. Реализованы адаптивная страница, калькулятор с дополнительными услугами, просмотр и локальное создание тестовой заявки, экспорт расчёта. Интеграция с CRM и Telegram не входит в текущую демонстрацию.

Следующий этап: по реальному заданию подключить серверное сохранение и уведомление, обработку повторов и ошибок, доступ менеджера. Такой этап требует выбора системы и доступов, поэтому не имитируется как готовый.
